# 🎮 Antigravity Multi-Agent Game Studio

Комплексный фреймворк виртуальной игровой студии, специализированных скилов (Skills) и инструментов MCP для среды **Google Antigravity** (Gemini Code Assistant / IDE).

Этот репозиторий превращает AI-ассистента в слаженную команду разработчиков видеоигр, готовую создавать проекты на **Godot Engine**, **Roblox Studio**, генерировать 3D-ассеты в **Blender**, моделировать игровую экономику и автоматически готовить проекты к публикации на платформах вроде **Яндекс Игр**.

---

## 🏛️ Архитектура студии (Ролевая модель)

Вся работа ассистента регламентируется правилом [`rules/game_studio_team.md`](rules/game_studio_team.md), которое обязывает проводить междисциплинарное обсуждение каждой задачи и возвращать готовый технический результат.

1. **Менеджмент и вижн**:
   * **Продюсер / Lead**: контроль скоупа, дедлайнов, отсечение избыточных фич (feature creep).
   * **Креативный директор / Product Owner**: сохранение ключевого вижна, целевая аудитория, уникальные торговые преимущества (USP).
2. **Дизайн и баланс**:
   * **Геймдизайнер (GD)**: core gameplay loop, механики, мета-прогрессия.
   * **Дизайнер экономики и баланса**: математические формулы, баланс источников и поглотителей ресурсов (sinks/faucets).
   * **Левел-дизайнер**: геометрия, блокауты, навигация, точки интереса, пейсинг уровней.
   * **Нарративный дизайнер / Сценарист**: лор, сюжетные арки, квесты и диалоговые деревья.
3. **Технический блок**:
   * **Техлид / Системный архитектор**: выбор паттернов, API-контракты, структуры данных, чистота архитектуры.
   * **Gameplay-программист**: физика, механики, контроллеры персонажей, искусственный интеллект (FSM / Utility AI).
   * **Backend / Network-программист**: клиент-серверная синхронизация, мультиплеер, авторизация.
   * **UI/UX-разработчик**: логика интерфейсов, экраны, HUD, меню и адаптивность.
4. **Арт, аудио и визуал**:
   * **Концепт-художник / 3D-моделлер**: визуальный стиль, пайплайны моделирования, текстуры и материалы.
   * **Технический артист (Tech Art)**: шейдеры, оптимизация графики (LOD, draw calls), риггинг, анимация.
   * **Саунд-дизайнер / Композитор**: пространственный SFX, звуковой отклик, адаптивное аудио.
5. **Тестирование и контроль качества (QA)**:
   * **Функциональный тестер (Manual QA)**: проверка механик по тест-кейсам, поиск регрессий, составление шагов воспроизведения.
   * **Геймплейный тестер / Плейтестер**: читаемость визуала, эргономика управления, кривая обучения, 'fun-фактор'.
   * **QA-автоматизатор**: автотесты, боты-стресс-тестеры, проверка пропускной способности.
   * **Security / Anti-Cheat QA**: поиск уязвимостей на клиенте, дюп предметов, спидхаки, валидация авторитета сервера.
6. **Аналитика и оперирование**:
   * **Дата-аналитик**: воронки прохождения, телеметрия, поиск точек отвала игроков.
   * **Комьюнити-менеджер**: сбор отзывов сообщества и выявление массовых проблем.

## 🔌 Интеграция Model Context Protocol (`mcp/`)

В каталоге [`mcp/`](mcp/) собраны серверные конфигурации и локальные прокси-мосты:
* **Godot MCP Server** (`@satelliteoflove/godot-mcp`): запуск CLI-сервера для прямого чтения и редактирования нод в редакторе Godot.
* **Roblox Studio MCP Proxy** (`roblox_mcp_proxy.js`): локальный серверный мост для взаимодействия со скриптами и объектами внутри Roblox Studio через HTTP/WebSocket плагин.
* **Blender MCP** (`blender-mcp` via `uvx`): программное моделирование и экспорт ассетов из Blender.
* Шаблон для новых сред доступен в [`mcp/mcp_config.example.json`](mcp/mcp_config.example.json).

## 🚀 Установка на любой ПК (Развертывание)

Для быстрой установки всех скилов и правил на новом компьютере запустите скрипт в PowerShell:

```powershell
.\install.ps1
```

Скрипт скопирует правила и скилы в глобальную папку Antigravity (`~/.gemini/config/`), где среда мгновенно сделает их доступными для всех ваших сессий и проектов.

## 📦 Как опубликовать этот репозиторий через GitHub Desktop

1. Откройте приложение **GitHub Desktop**.
2. В верхнем меню выберите **File** ➔ **Add Local Repository...** (сочетание клавиш `Ctrl + O`).
3. В поле **Local path** укажите путь к репозиторию:
   ```text
   %USERPROFILE%\Documents\GitHub\antigravity-game-studio
   ```
4. Нажмите **Add Repository**.
5. Нажмите синюю кнопку **Publish repository** на верхней панели:
   * Задайте имя (например, `antigravity-game-studio`).
   * Снимите галочку *Keep this code private*, если хотите сделать репозиторий открытым (Public), либо оставьте её, если хотите приватный репозиторий.
   * Нажмите **Publish repository**.
