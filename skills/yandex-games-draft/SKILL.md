# Yandex Games Single-Draft Generator Protocol

Автономный регламент сбора данных по текущему проекту и генерации **единого готового файла черновика (`YANDEX_GAMES_DRAFT.md`)** для консоли разработчика Яндекс Игр (Yandex Games Developer Console) с генерацией обязательных графических ассетов.

---

## 1. Правило триггера и строгой изоляции
- **Скил спит по умолчанию.** Запрещено вызывать его превентивно, предлагать при разработке механик, интеграции SDK или обычном общении.
- **Фразы активации:**
  > «подготовь черновик яндекс игр» / «черновик яндекс игр»
  > «сделай черновик для яндекс игр» / «карточка яндекс игр»

---

## 2. Этап 1: Экспресс-аудит проекта (Zero-Token & True-to-Game Inspection)
При получении триггерной фразы агент выполняет экспресс-диагностику проекта с акцентом на **100% достоверность (No Mislead)**:
1. Проверить наличие `PROJECT_INDEX.md`, манифестов (`project.godot`, `package.json`, `index.html`), структуры папок и ассетов.
2. Точно извлечь фактические данные об игре:
   - **Реальный визуальный стиль:** строго определить стиль графики проекта (*Pixel Art, Low-Poly 3D, Stylized 2D Cartoon, Voxel, Realistic 3D, Minimalist Flat*).
   - **Главный герой и знаковые объекты:** имя/вид протагониста, ключевые враги, собираемые ресурсы или транспорт (только то, что реально есть в коде и ассетах).
   - **Реальный кор-геймплей:** фактическое действие игрока (прыжки по платформам, объединение фишек, уклонение от препятствий, клики по объекту). Запрещено придумывать несуществующие механики!
   - **Схема управления:** реальные бинды клавиш и сенсорного ввода из скриптов.

---

## 3. Этап 2: Верификация облачных сохранений
Проверить кодовую базу на интеграцию Yandex Games SDK:
- Поиск сигнатур сохранения: `ysdk.getPlayer()`, `setData`, `setStats`, `YaGames.init()`, специализированных плагинов для движка (Godot, Unity, Construct).
- **Результат:**
  - Если сохранения в профиль игрока Яндекс Игр реализованы -> `Игра использует облачные сохранения: Да`.
  - Если данные хранятся только локально (`localStorage`, локальные файлы) или прогресс не сохраняется -> `Игра использует облачные сохранения: Нет`.

---

## 4. Этап 3: Высокочастотные метаданные и вирусные ключи
Сформировать метаданные с прицелом на максимальный органический охват в каталоге ЯИ:
- **Возрастной рейтинг (Traffic Maximize):** Выбрать минимально возможный обоснованный ценз (`0+`, `6+` или `12+`), чтобы охватить максимальное ядро аудитории ЯИ. Цензы `16+`/`18+` ставить только при наличии явного насилия/хоррора в кодовой базе.
- **Категории:**
  - *Основная категория:* Строго по фактическому жанру игры (*Аркады, Казуальные, Симуляторы, Головоломки, Экшен*).
  - *Дополнительная категория:* Честная смежная категория из рубрикатора ЯИ.
- **Теги (5–10 шт.):** Реальные механики игры из каталога ЯИ (*раннер, физика, реакция, выживание, зомби, кликер*).
- **Поисковые ключи (10–15 шт.):** Высокочастотные поисковые фразы Яндекса, точно отражающие реальный процесс игры.

---

## 5. Этап 4: Честный High-CTR копирайтинг (100% True-to-Game)
**ЖЕЛЕЗНОЕ ПРАВИЛО:** Никакого ложного кликбейта (Misleading). Тексты обязаны драйвово и захватывающе описывать **только реальный игровой процесс**. Обман карается баном модерации и 90% отвалом игроков в первые 10 секунд!

| Поле | Максимум | Правило честной виральности и высокого CTR |
| :--- | :--- | :--- |
| **Название (Title)** | **до 50 символов** | **Формула:** `[Хук-челлендж / Интрига] + [Реальная суть игры]`. Опирается на настоящего героя или механику (например: *«Побег от Лавы: Паркур Шахтера»*, а не абстрактный космос, если игра про шахту). Без CAPS LOCK, без запрещенных слов («бесплатно/онлайн»). |
| **Короткое описание (Short)** | **до 70 символов** | Честный вызов на основе реальной сложности/цели игры (например: *«Уворачивайся от пил, собирай кристаллы и дойди до 50 уровня!»*). |
| **Описание для SEO** | **до 160 символов** | Концентрированная суть реального геймплея с поисковыми ключами для поисковика Яндекса. |
| **Об игре (About)** | **до 1000 символов** | **Честная модель AIDA:**<br>1. Яркое вступление, описывающее стартовую ситуацию в игре.<br>2. Реальные фичи игры по буллетам с эмодзи: конкретные виды врагов, реальные апгрейды, боссы, уровни, которые есть в проекте.<br>3. Призыв поставить рекорд в таблице лидеров. |
| **Как играть (How to play)** | **до 1000 символов** | Точнейшая инструкция: ПК (WASD/стрелки/мышь), Сенсор (свайпы/тапы). Фактическая цель для победы и условия поражения. |

> **КРИТИЧЕСКИЙ КОНТРОЛЬ:** Перед записью агент валидирует точную длину строки каждого блока (`len <= limit`).

## 6. Этап 5: Генерация честных High-CTR визуальных ассетов (Без текста)
Картинки обязаны **достоверно отражать стилистику и геймплей игры** (требование п. 2.4 правил Яндекс Игр). Запрещено генерировать фотореализм, если игра пиксельная или двухмерная!

1. **Иконка (512×512 px, PNG — Фокус на реальном герое/объекте):**
   - Вызвать инструмент `generate_image`:
     - `AspectRatio`: `'1:1'`
     - `ImageName`: `'yandex_icon_512'`
     - `Prompt`: Крупный план **реального персонажа или ключевого предмета из игры** в **фактическом арт-стиле проекта** (`in exact [ArtStyle: pixel art / 2d stylized / low-poly 3d / voxel / etc.]`). Живая эмоциональная мимика, высокий контраст, чистый силуэт. Строго: `NO text, NO letters, NO words, NO typography, NO UI buttons, NO misleading content`.
2. **Обложка (800×470 px / 16:9, PNG — Кульминация реального геймплея):**
   - Вызвать инструмент `generate_image`:
     - `AspectRatio`: `'16:9'`
     - `ImageName`: `'yandex_cover_800'`
     - `Prompt`: Динамичная сцена, изображающая **фактический игровой процесс** (реальная локация, реальные препятствия/враги игры) в **стиле игры** (`authentic [ArtStyle] game promo cover showing actual gameplay situation`). Кинематографичный свет, яркая композиция. Строго: `NO text, NO title, NO watermark, NO logo, NO letters, NO fake elements`.
3. Сохранить файлы и добавить ссылки в готовый черновик.
